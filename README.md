# samvardhanstudios.com

The studio website, kept on its own branch, separate from the game code.

- `/`: studio home
- `/sandstone-kingdom/`: game page
- `/sandstone-kingdom/privacy/`: privacy policy (use this URL in Play Console)
- `/sandstone-kingdom/terms/`: terms of service
- `/sandstone-kingdom/age-rating/`: age rating and content
- `/ads.txt` and `/app-ads.txt`: put your AdMob publisher ID in both

To publish with GitHub Pages: repo Settings > Pages > Deploy from branch `website` / root.
The `CNAME` file sets the custom domain. Point the domain's DNS at GitHub Pages
(A records 185.199.108.153, .109.153, .110.153, .111.153), then tick "Enforce HTTPS".

Have the privacy policy and terms reviewed by a lawyer before launch, and add your registered
business address.
