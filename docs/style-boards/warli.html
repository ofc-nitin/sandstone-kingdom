Almost everything is rice paste on the wall. Turmeric marks goals and time; leaf is saved for rare moments. No pure white, no gradients.

Type

Yatra One

Kalam, a handwritten face, for everything you read: like notes beside the painting.

Both free (SIL Open Font License), both from Indian type designers.

Figures

Every figure is made of circles, triangles and lines, exactly how Warli is painted, so the code can draw an endless cast in one consistent hand.

Controls

Hand-painted panels, not pills. Progress is a dance circle that fills with dancers, not a bar or stars.

The win moment

Everyone is home.

The wall grows by one scene. Wall 3 has 4 scenes left.

Each solved level paints a new scene onto one long village wall, which is the level select. The wall becomes the player's own mural.
